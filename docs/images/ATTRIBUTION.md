# Images

`cover.png` is a generated illustration for the GitHub landing page. It is
decorative artwork, not a screenshot of the app.

`phone-overview.png`, `phone-workspace.png`, and `ipad-workspace.png` are raw
simulator captures of the current app, launched from its DEBUG visual fixtures
with synthetic Example Mac session data. They are not a live SSH, APNs, or
saved-host session.

No private host names, credentials, or local paths are in these files.
Screenshot EXIF is color space and pixel size only.

App icon and connect mark provenance remains in
[App/Assets.xcassets/ATTRIBUTION.md](../../App/Assets.xcassets/ATTRIBUTION.md).
